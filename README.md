# FOURWARD — 로컬 네트워크 협동 운동회 MVP

최대 5개 조, 조당 1~4명. 사회자도 조에 참여해 플레이할 수 있으며, 참여하면 조 인원에 포함됩니다.
Vite + TypeScript 화면과 Python 표준 라이브러리 서버를 사용합니다. 배포본의 `dist/`를 함께 두면 플레이에 Node.js나 외부 Python 패키지가 필요 없습니다. 프런트엔드 수정·빌드 방법은 [FRONTEND.md](FRONTEND.md)를 참고하세요.

## 직접 플레이 테스트

`python3 game_test.py` (Windows: `py game_test.py` 또는 `start_game_test.bat`) 실행 후 http://127.0.0.1:8000 에 접속하세요. 첫 참가자가 자동으로 사회자가 되며, GAME TEST 패널에서 게임 선택·재시작·AI 팀원 수를 설정할 수 있습니다. 자세한 방법은 [GAME_TEST.md](GAME_TEST.md)를 참고하세요.

## 1. 서버 실행

서버 PC에 Python 3.9 이상을 준비하고 이 폴더를 압축 해제합니다.
폴더에서 터미널을 열고 실행합니다.

Windows:
```powershell
py server.py
```

Ubuntu / macOS:
```bash
python3 server.py
```

접속 주소와 사회자 PIN이 터미널에 표시됩니다. 이 터미널은 경기 내내 열어 두세요.
8000 포트가 사용 중이라면 `python3 server.py --port 8080` 또는 `py server.py --port 8080`을 사용합니다.

## 2. 접속

- 사회자 PC: `http://127.0.0.1:8000`
- 참가자: 같은 Wi-Fi/유선 LAN에서 `http://서버PC의LAN_IP:8000`
- 예: 서버 주소가 192.168.0.15라면 `http://192.168.0.15:8000`
- 참가자 기기의 `localhost`나 `127.0.0.1`로는 서버 PC에 접속되지 않습니다.
- `index.html`을 더블클릭하는 방식이 아닙니다. 반드시 서버 주소로 접속합니다.
- 서버가 표시하는 주소가 여러 개면 같은 공유기의 LAN 주소를 선택합니다. Windows `ipconfig`, Linux `hostname -I`로도 확인할 수 있습니다.
- Windows 방화벽 알림이 나오면 신뢰하는 개인 네트워크에 한해 Python 연결을 허용하세요. 방화벽 전체 해제나 인터넷 포트포워딩은 필요 없습니다.
- 게스트 Wi-Fi/학교 AP가 기기 간 통신을 차단하면 접속되지 않을 수 있습니다. 기기 간 통신이 허용된 공유기를 사용하세요.

## 3. 진행 순서

1. 이름으로 입장한 후 서버 터미널의 PIN으로 사회자석에 앉습니다. 직접 플레이하려면 조의 `＋ 참여`를 누르거나 `플레이어로 참가하고 시작`을 누르세요. 후자는 빈자리에 자동 편성한 뒤 경기를 시작합니다. 관전만 하려면 `관전으로 시작`을 선택하세요. 기존 조에서 사회자가 되면 편성이 유지됩니다.
2. 참가자는 이름으로 입장하고 조의 `＋ 참여`를 누릅니다.
3. 사회자는 조 수를 2~5개로 조절하고 필요하면 랜덤 섞기를 합니다.
4. 랜덤 섞기는 온라인 참가자 모두를 배정합니다. 사회자는 이미 조에 참여한 경우 함께 섞이며, 중계만 하는 사회자는 제외됩니다. 별도의 관전자를 제외할 필요가 있으면 수동 편성을 사용하세요.
5. 참여 조마다 1~4명이면 경기 시작. 한 조만 있어도 진행할 수 있고, 총 2~3명도 1인 조를 포함해 나눠 플레이할 수 있습니다. 빈 조는 경기에 포함되지 않습니다.
6. 매 스테이지는 조 번호 순서대로 한 조씩 진행합니다. 각 조는 4초 준비 후 플레이합니다. 미로는 한 미로마다 다음 조로 넘어가 총 3회 순환하고, 줄넘기는 조당 120초, 계주와 박은 최대 180초입니다. 완주하거나 시간이 끝나면 다음 조가 자동으로 준비를 시작합니다. 모든 조의 차례가 끝나면 스테이지 결과가 표시됩니다.
7. 사회자가 다음 스테이지를 시작합니다. 마지막은 누적 점수로 공동 우승까지 표시합니다.
8. `대기실로`는 점수와 경기 기록을 초기화합니다. 참가자 이름과 조 편성은 유지됩니다.

## 4. 경기 규칙

### 임시 AI로 혼자 테스트하기

사회자로 입장한 뒤 각 조의 `＋ 임시 AI` 버튼으로 자동 참가자를 한 명씩 추가합니다.
한 개 이상의 조에 1~4명을 구성하면 경기 시작이 가능합니다. 본인 혼자 조에 참여해도 AI 없이 시작할 수 있습니다. 직접 플레이하려면 본인도 `＋ 참여`를 누르세요. 예를 들어 1조에 본인＋AI 1명, 2조에 AI 2명을 배치하면 됩니다. 사회자도 경기 시작·일시정지·다음 스테이지 버튼을 계속 사용할 수 있습니다. 이미 관전으로 시작한 경기에서는 `AI 자리로 플레이 참가`로 아직 경기가 끝나지 않은 조의 AI 자리를 넘겨받을 수 있습니다. 팀 인원, 진행도, 시도 횟수와 경기 시간은 유지됩니다. `조에서 나가기 / 대기로`를 눌러도 사회자 권한은 유지됩니다.
AI는 네 경기 모두 자동으로 입력하며 사람과 같은 인원 보정·점수·입력 제한을 적용받습니다.
사람과 AI를 같은 조에 배치할 수도 있습니다. 미로에서는 사람이 맡은 방향은 직접 입력해야 합니다.
AI는 테스트용으로 정확한 박자를 사용하므로 실전 경쟁용 난이도는 아닙니다.

대기실에서 `AI 1명 제거` 또는 `임시 AI 전체 제거`로 삭제합니다.
랜덤 섞기에 AI도 포함되며, 조 수를 줄여 대기 인원으로 이동한 AI는 전체 제거로 삭제할 수 있습니다.
`대기실로`로 돌아오면 AI 편성도 유지됩니다. 서버를 종료하면 AI는 사라집니다.

| 스테이지 | 입력 / 목표 | 보정 |
|---|---|---|
| 협동 미로 | 15×15 → 19×19 → 23×23 미로 3개, 한 미로마다 다음 조로 순환 | 4명 U/D/L/R, 3명 UD/L/R, 2명 UD/LR, 1명 UDLR |
| 리듬 계주 | 5개 레인의 오른쪽에서 왼쪽으로 이동하는 방향키 + Space 노트 7개 패턴을 반복 입력하며 60초 달리기 | 놓친 노트마다 뒤로 이동하고 1초 추가 |
| 줄넘기 | 줄이 발밑에 올 때 Space, 120초 동안 성공 점프 누적 | 성공한 플레이어 점프 1회 = 1점 |
| 박 터뜨리기 | 바 중앙에서 Space, 중앙30/안쪽20/가장자리10 피해 | 체력 = 팀 인원 × 300 |

- 미로: 각 조는 세 회차에 서로 다른 무작위 출발 모서리를 받으며 출구는 반대 모서리입니다. 파란 칸은 출발점, 녹색 칸은 출구입니다. 한 방향으로 연속 이동하는 직선 구간은 최대 3칸입니다. 매 경기 서로 다른 지도를 생성하며, 같은 회차에서 모든 조의 최단 경로 길이를 동일하게 맞춥니다. 회차마다 크기가 커지고 분기점이 있는 새 미로를 제공합니다. 구조와 갈림길 차이에 따른 체감 난도는 남습니다.
- 계주: 현재 주자만 입력. 한 패턴은 방향키 5개 + Space 2개이며 ±0.16초 허용. 패턴과 주자 교대마다 직전과 다른 키 패턴과 리듬을 생성합니다. 노트 간격은 0.36/0.48/0.60초가 각각 두 번씩 등장하며 순서를 섞습니다(첫 노트부터 마지막 노트까지 2.88초). 패턴이 끝나면 다음 주자가 새 패턴을 받습니다. 각 노트의 MISS는 한 번만 계산하며 1초의 지연을 추가합니다. 기본 완주 시간은 60초이며 안전 제한시간은 180초입니다. 오른쪽에서 오는 노트가 왼쪽 노란 판정선에 닿을 때 입력하세요. 다음 주자는 해당 카운트다운 때 공개됩니다.
- 줄넘기: ±0.12초 허용. 회차당 1회만 시도 가능하며 이른 입력도 시도를 소비합니다. 조마다 8박 패턴이 다릅니다. 0.60/0.72/0.84/0.96초 간격(최대 100 BPM)이 각각 두 번씩 등장하며 순서만 다르게 섞입니다. 패턴 전체와 다음 BPM을 화면에서 확인할 수 있습니다. 120초를 모두 진행하며 성공한 점프 수가 점수가 됩니다. `박자 소리 켜기`로 보조음을 켤 수 있습니다.
- 박: 바 주기 2.0초. 중앙 구간에서는 위치가 시간 비율 대비 1.5배 속도로 이동합니다. 중앙 ±1.8% / 안쪽 ±5% / 가장자리 ±9%에서 각각 30/20/10 피해를 줍니다. 주기당 1회 공격, MISS도 시도를 소비합니다. 팀원별 바 시작 위치가 다릅니다.
- 모바일은 화면 버튼, PC는 방향키/Space. 키를 누른 채로 유지하는 자동 반복은 무시됩니다.
- 화면 왼쪽에는 조별 대기·진행·완료 상태와 누적 점수, 오른쪽에는 현재 경기 중인 한 조의 중계가 나옵니다. 대기 중이거나 차례가 끝난 조의 입력은 차단됩니다.

화면은 크림색 배경과 단풍색·황토색·올리브색의 가을 운동회 테마를 사용합니다.
3스테이지에서는 현재 BPM에 맞춰 줄이 회전하고, 실제 Space 입력을 받은 참가자의 캐릭터가 점프합니다.
성공 입력은 캐릭터 강조로 표시되며 일시정지하면 줄과 점프 동작도 멈춥니다.

## 5. 순위

- 미로: 조 번호 순으로 한 미로씩 3회 순환합니다. 세 미로의 합산 플레이 시간이 짧은 순으로 100/80/60/40/20점. 미완주는 완료한 미로 수로 순위를 정합니다. 각 미로 제한시간은 180초입니다.
- 계주: 기본 60초 + 놓친 노트 수(초). 점수는 max(0, 180 − 완주 시간)이며 60초 완주 시 120점입니다. 제한시간 내 미완주는 0점입니다.
- 줄넘기: 각 조에 120초. 성공한 플레이어 점프 한 번마다 1점이며 순위에 따른 점수 변환은 없습니다. 팀 인원이 많으면 총 성공 수를 늘릴 수 있습니다.
- 박: 완주 시간/진행률 순위별 100/80/60/40/20점입니다.
- 준비·대기·일시정지 시간은 기록에서 제외합니다. 동률은 공동 순위, 다음 순위는 건너뜁니다. 총점 동점은 공동 우승입니다.

## 6. 연결·제한사항

- 상태는 서버가 공유하며 약 0.18초 간격으로 가져옵니다. 움직이는 바와 박자는 클라이언트에서 부드럽게 그립니다.
- 판정은 서버가 입력을 받은 시각 기준입니다. 표시 시계는 왕복 지연으로 근사 보정하지만 입력 지연 자체는 보상하지 않습니다. 서로 다른 기기·Wi-Fi 지연으로 판정 오차가 생길 수 있는 레크리에이션용 MVP입니다.
- 실전 전에 동일 환경에서 짧게 연습하세요. 공식 경쟁용 정밀 지연 보정과 안티치트는 미포함입니다.
- 한 브라우저 프로필은 참가자 한 명입니다. 여러 명을 PC 하나로 테스트하려면 별도 브라우저 프로필/브라우저를 사용하세요. 일반 탭은 토큰을 공유합니다.
- 새로고침 시 같은 브라우저에서 기존 참가자로 복귀합니다. 시크릿 창을 닫거나 사이트 데이터를 지우면 복귀 정보가 사라집니다.
- 접속 끊김은 이름 옆에 표시됩니다. 자동으로 인원 보정을 다시 적용하지 않습니다. 사회자가 일시정지 후 재접속을 기다려 주세요.
- 서버 재시작 시 경기·명단·점수는 초기화됩니다. 영구 저장, 기권 참가자 삭제, 개별 스테이지 연습, 관전자 전용 비밀권한은 미포함입니다.
- HTTP 신뢰 LAN용입니다. 인터넷에 직접 공개하지 마세요. 사회자 PIN은 서버 터미널에서만 확인할 수 있습니다.
- 리듬 계주 향후 주자 순서는 클라이언트에 공개하지 않습니다. PIN과 다른 사람의 참가자 토큰도 응답에 포함하지 않습니다.
- 미로는 인원이 적으면 소통 부담이 줄어듭니다. 1인 조는 모든 방향과 모든 계주 패턴을 혼자 담당합니다. 인원 보정은 완전한 경쟁 균형을 보장하지 않으므로 가능하면 동일 인원 편성을 권장합니다.
