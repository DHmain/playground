# 깡통 착륙 독립 데모

본게임 대기실에서 선택형 협동 튜토리얼로 제공하는 4인 물리 프로토타입입니다. 본경기 점수에는 영향을 주지 않습니다. Vite 빌드에 포함되므로 본게임 서버만 실행하면 이용할 수 있습니다.

아래 방법으로 독립 데모도 계속 실행할 수 있습니다. Python 표준 라이브러리만 필요합니다.

```powershell
py demos/landing/server.py
```

브라우저에서 http://127.0.0.1:8010 접속. 기본은 1인 연습 모드이며 A/L/U/D 또는 방향키로 모든 역할을 조작합니다. 모바일은 버튼을 누르고 있습니다.

4개 기기로 테스트하려면 신뢰하는 같은 LAN에서 다음 명령으로 실행하고, 각 기기에서 서버 PC의 LAN IP와 8010 포트로 접속합니다. 각자 역할을 하나씩 선택합니다.

```powershell
py demos/landing/server.py --bind 0.0.0.0
```

- 하단 왼쪽 분사기: 왼쪽으로 추진. 하단 오른쪽: 오른쪽으로 추진. 회전 없음.
- U: 출력 증가. D: 감소. 동시 입력: 유지. 모두 놓으면 출력 즉시 0. 재점화는 U부터.
- 시작 공유 연료 50, 메인 최대 초당 3.2, 보조 각각 초당 0.55 소비.
- 일정한 초기 조건과 시간 기반 바람. 고정 60 Hz 서버 물리 계산.
- 60초 내 착륙장 중심 ±7.5m에 수직 5m/s 이하, 수평 3m/s 이하로 접촉 후 2초 안정 유지.
- 중앙 최대 100점, 거리 비례 감점. 추락·장외·시간 초과 0점. 전복 판정 없음.
- 통신이 끊기거나 탭이 멈추면 입력은 마지막 갱신 후 0.65초에 해제.

실험용으로 역할 독점·진행자 인증·결과 저장은 없습니다. 여러 사람이 같은 역할을 선택할 수도 있으며 누구나 재시작할 수 있습니다. 공개 인터넷 서비스용이 아닙니다. 실제 4인 터치 조작과 재미·난이도는 플레이테스트가 필요합니다.
